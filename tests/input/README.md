# Входные данные тестов

`SMHome_UniversalRound_ESP32_C3_Mini_v4/` — копия необходимых для импорта файлов
проекта KiCad, предоставленного пользователем, на 19 ноября 2026 года.
Имена файлов и связи между листами сохранены:

- `SMHome_UniversalRound_ESP32_C3_Mini_v4.kicad_pro` — проект;
- `SMHome_UniversalRound_ESP32_C3_Mini_v4.kicad_sch` — корневая схема;
- `ExtConnectors.kicad_sch` — дочерний лист;
- `PowerSupply.kicad_sch` — дочерний лист;
- `components.expected.json` — эталон 49 позиций (значения и посадочные места),
  полученный из XML netlist экспортом `kicad-cli`.

Плата, резервные копии, Gerber, 3D-модели и внешние библиотеки для этих тестов
не требуются: размещённые символы уже встроены в схемы.

Тесты в `tests/kikad_plugin` читают этот набор. Для проверки изменений и удаления
файлов создаются временные копии. Исходный проект пользователя не используется.


Проверка: `python -m unittest discover -s tests/kikad_plugin -v` из корня PartsDB.
При наличии `kicad-cli` или переменной `KICAD_CLI` дополнительно выполняется
сверка с новым экспортом KiCad. `tests/input/` исключён из очистки тестовых БД:
даже файлы с именем бэкапа внутри входных данных сохраняются как фикстуры.
