# Единицы СИ, базовые типы и приложения проектов — PartsDB 2.0

Актуальность: 21 ноября 2026. Версия схемы БД: **11**.
SQL и миграции находятся в `ElData/ElDBScheme.py`, работа с SQLite — в
`ElData/ElDBConnect.py`, доступ к справочникам — в `ElData/ElDBDataUnits.py`.

## Редактирование справочников

Откройте **Настройки → Единицы измерения и базовые типы…**. Поведение окна задаёт
`ElUnitsDialog.py`, форму — `qt/ElUnitsWnd.ui`, подписи — `ElWindowTexts.py`.

На вкладке единиц доступны английское и русское названия, обозначения, множитель
и основная единица, а также колонка «Алиасы». ID назначается автоматически и не редактируется. Начальное
заполнение содержит 125 строк: пять основных единиц и их варианты с 24 приставками СИ.

| Пример | marker | marker_ru | multiply | Основная единица |
|---|---|---|---|---|
| Ohm / Ом | R | Ом | 1 | пусто |
| Kiloohm / Килоом | k | к | 1000 | Ohm |
| Microhenry / Микрогенри | uH | мкГ | 0.000001 | Henry |
| Nanofarad / Нанофарад | nF | нФ | 0.000000001 | Farad |

Значение в основной единице = введённое значение × `multiply`. Множитель должен
быть конечным положительным числом; при вводе допускаются точка и запятая.
Английские названия и обозначения используют ASCII, например `uH`.

Колонка **Основная единица СИ** содержит список названий единиц с множителем 1.
У основной единицы ссылка пустая; для единицы с приставкой она обязательна.
Можно добавить основную единицу и сразу сослаться на неё из другой новой строки,
не закрывая диалог. Цепочки ссылок и ссылки на удалённые строки не сохраняются.

На вкладке базовых типов редактируются название, позиционное обозначение, иконка
и основная единица. Начальные связи: Capacitor → Farad, Resistor → Ohm,
Inductor → Henry. Для типа без единой единицы оставьте поле пустым.

Кнопки добавления создают новые строки. Удаление требует подтверждения.
**Сохранить** проверяет и записывает оба справочника одной транзакцией;
**Отмена** отбрасывает изменения. Тип по умолчанию и типы, используемые разделами
каталога, удалить нельзя. Чтобы удалить основную единицу, сначала удалите её
производные единицы или переназначьте ссылки, а также очистите ссылки типов.
Изменение справочников не переписывает текстовые единицы или `reduced_val` в `PARTS`.

## Алиасы единиц СИ

В строке нужной единицы заполните колонку **«Алиасы»** через запятую или точку
с запятой. Например, для Kiloohm: `кОм, kR, kΩ, kOhm`. Алиасы могут содержать
русские буквы и символ Ω; ограничение ASCII относится только к основным английским
полям. Непустое обозначение ссылается на ту же единицу и использует её множитель
и связь с основной единицей.

**Сохранить** записывает алиасы и оба справочника одной транзакцией, затем
обновляет кандидатов в открытом проекте без переимпорта; **Отмена** отбрасывает правки. Удалённые алиасы не восстанавливаются при следующем открытии.
При удалении единицы удаляются и принадлежащие ей алиасы.

Сопоставитель читает алиасы из БД, не генерирует их сам. Обозначение Value и
обозначение справочника переводятся в верхний регистр. При коллизии разных
множителей сохраняются все кандидаты, без автоматического подтверждения связи.
При создании БД или миграции 10 → 11 автоматически появляются полные формы
сопротивлений, включая `кОм` и `МОм`.

## Внешнее приложение проекта

В **Настройки → Плагины…** выберите импортёр и заполните **Путь к приложению**
и **Параметры**. Кнопка рядом с путём открывает стандартный файловый диалог.
Например, для прямого исполняемого файла KiCad задайте параметры `"{file}"`.

Настройки сохраняются для каждого плагина в текущей БД при закрытии окна, в том
числе через Escape и системную кнопку. Переключение карточки или языка сохраняет
незавершённые правки, синхронизация метаданных и обновление плагина не сбрасывают
сохранённые путь и параметры. Удаление плагина удаляет и его настройки запуска.

Выберите проект и нажмите **Открыть приложение**. Контроллер `ElProjWindow.py`
использует настройки из `PLUGINS` по `PROJECTS.plugin_id` и источник `source_uri`,
переданный при импорте. `file://` декодируется в локальный путь; сетевой URI
передаётся без изменения. Аргументы разбираются до подстановки `{file}`, поэтому
пробелы и кавычки внутри пути проекта остаются частью одного аргумента.
В шаблоне параметры с пробелами заключайте в кавычки. Командная оболочка не используется.

На macOS поддерживаются исполняемые файлы и пакеты `.app` через
`/usr/bin/open -a … --args`. Для уже работающего `.app` обработка параметров
зависит от самого приложения; для передачи параметров новому процессу можно
указать непосредственно его исполняемый файл в `Contents/MacOS`.
Запуск через `QProcess.startDetached` не привязывает внешний процесс к PartsDB:
он продолжает работу после закрытия склада. Неудача запуска показывается в окне ошибки.

## Генерируемые формы и проверки

`updateui.sh` создаёт Python-формы и ресурсы штатными генераторами. Выходные файлы
не изменяются и не дополняются комментариями или docstring, в том числе через
скрипты постобработки. Описания классов и методов в формате YARD относятся только
к коду, написанному вручную.

`tests/test_units_and_launch.py` проверяет множители, редактирование и отмену,
ссылки на новые единицы, защиту связей, откат миграций и параметры независимого запуска.
Полный прогон: `./build.sh -t`.

## Алиасы типов

В таблице базовых типов колонка **Алиас типа** содержит ссылку на ID другого
типа. Пустое значение означает обычный тип. В выпадающем списке доступны
обычные типы, включая добавленные в текущем окне; сама строка исключена.
Выбор пустой строки снимает ссылку. При переименовании связанного типа
подпись обновляется, ID сохраняется. Ссылки на алиасы и отсутствующие типы
не сохраняются; сначала снимите или переназначьте такие ссылки.

## Что даёт базовый тип секции и назначенная ему единица СИ

Базовый тип связывает произвольное название секции с категорией компонента.
Это задаёт область поиска по Kind, включая дочерние секции и алиасы типов,
а также исходные ключевые поля каталога. Новый дочерний раздел наследует тип
родителя; уже существующие разделы сохраняют собственные назначения.

Назначенная базовому типу единица СИ определяет размерность номинала:
Resistor → Ohm, Capacitor → Farad, Inductor → Henry. В `parts_tbl_view` колонка
`units` показывает выпадающий список основной и всех мультиплицированных единиц
этой размерности, включая их маркеры и алиасы. Без назначения СИ остаётся обычный
текстовый редактор. Алиас базового типа использует размерность канонического типа.

При создании карточки и сохранении изменений `value`, `units` или
`reduced_val_units` вычисляется `reduced_val = value × multiply`, а
`reduced_val_units` получает английский маркер основной единицы. Например,
4.7 кОм → 4700 R; 100 нФ → 0.0000001 F. В существующем каталоге
написание `мОм` означает МОм, поэтому сохраняется преобразование в мегаомы;
для миллиомов используется `mR`. Пустой номинал или неизвестная/неоднозначная
единица очищает reduced_val, чтобы не оставалось старого результата.
Назначение размерности не переписывает все карточки задним числом: расчёт
происходит при создании или сохранении карточки.

В справочнике Basic types самая левая видимая колонка — иконка. Её отображает
общий `IconCellDelegate` из `ElCommonUI.py`, тот же делегат используется для
складских карточек. Пустой путь показывает пустую ячейку, готовую принять drop;
у базовых типов нет автоматического подбора картинки по объекту Part.
Отсутствующий или повреждённый файл отображается как недоступная картинка.

Перетащите изображение из файла или браузера на ячейку иконки. Общие функции
декодирования и сохранения находятся в `ElCommon.py`. Картинка преобразуется
в PNG и получает уникальное имя в `<main.data_path>/el_icons`; в `BASIC_TYPES.icon`
сохраняется абсолютный путь. Каталог определяется по конфигурации приложения,
а не по расположению SQLite-файла. Относительный data_path разрешается от папки
конфигурационного файла. Для диалога без конфигурации используется переданный
factory.dataPath, а при его отсутствии — папка SQLite-файла.

До Save изменяются только модель формы и созданный для неё PNG. Cancel удаляет
только новые файлы этой сессии. При повторном drop старый файл не перезаписывается;
после Save удаляются промежуточные PNG, не используемые сохранёнными строками.
Отложенный drop хранит устойчивый индекс: удаление строки не переносит картинку
на соседний тип, а отмена формы блокирует запись из ещё не выполненного drop.

Из `qt/resources.qrc` исключены изображения `qt/el_icons`: базовые типы больше
не используют встроенные Qt-пути. Исходные PNG остаются в `qt/el_icons` для
первоначального копирования. Начальная установка и назначение существующим типам
выполняются явно, вне миграций:

```sh
venv/bin/python tools/assign_basic_type_icons.py /path/to/catalog.sqlite \
  --data-path /path/from/config \
  --backup-dir /path/to/manual-backups
```

Сначала создаётся резервная копия БД, затем изображения копируются в el_icons
без перезаписи пользовательских файлов и сохраняются пути в BASIC_TYPES.icon.
Повторное копирование использует уже установленные одинаковые PNG.
Команда не запускает миграции. Ручную копию тестовой базы следует хранить
вложенно в tests/archives/backups, чтобы очистка временных тестовых копий её
не удаляла. Диагностика пути, drop, декодирования, сохранения, кеша и удаления
промежуточных файлов записывается в DEBUG-журнал; ошибки включают traceback.
