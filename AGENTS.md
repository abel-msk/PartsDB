# Правила проекта

## Автоматически генерируемые файлы

Python-файлы, которые генерирует `updateui.sh`, вручную не изменять:

- `ElParts.py`
- `ElAppPathWnd.py`
- `ElOpenFileWnd.py`
- `ElHdrEditWnd.py`
- `resources.py` (промежуточный файл `resources.pyx` также не редактировать вручную).

Изменения интерфейса и ресурсов вносить в исходные файлы `.ui`, `.qrc` и ресурсы, затем запускать `updateui.sh` для перегенерации. Поведение приложения изменять в файлах, написанных вручную. Это правило распространяется и на новые файлы, которые в дальнейшем будет генерировать `updateui.sh`.

## Тексты окон и языки

Подписи элементов интерфейса для двух языков задавать в отдельном модуле `ElWindowTexts.py`, отдельной функцией для каждого окна. Вызывать её из кода окна при инициализации после создания виджетов и при смене языка. Не вносить изменения для локализации в автоматически генерируемые Python-файлы. Каталоги переводов и управление языком находятся в `translations/` и `ElTranslations.py`.


## Тестовые базы и резервные копии

После успешного полного прогона тестов удалять временную `test_db.sqlite` в корне
проекта вместе с её SQLite sidecar-файлами и тестовые резервные копии
`*.sqlite.bak*`, `*.sqlite3.bak*`, `*.db.bak*` непосредственно в `tests/`.
При неудаче сохранять временную БД и три последних бэкапа каждой тестовой базы.
Использовать `tools/cleanup_test_databases.py --success` или `--failed`;
`build.sh -t` вызывает нужный режим автоматически. Исходную `tests/imported.sqlite`,
входные данные `tests/input/` и архивные фикстуры не удалять.
